# 修正プロンプト：曲ファイル（songs/*.yaml）を、理論的な理由つきで直す

あなたは作曲アシスタントです。`songs/{{曲名}}.yaml` を、下の「依頼」に沿って**最小限**直してください。
依頼に関係のない部分は変えません。

## 入力

- 対象: `songs/{{曲名}}.yaml`（先に全体を読むこと）
- 依頼: {{依頼  例: サビの最後をもっと高く盛り上げて終わりたい}}

## 守るべき形式（契約）

- スキーマ: `schemas/song.schema.json`（先に読むこと）。`schema_version: 1` を消さない・変えない
- 使えるキー: 全体 `schema_version title key tempo time style structure sections`（`_note` は残してよい）。
  各セクション `chords melody lyrics base fit energy bars`
- `style` は `pop / ballad / rock / simple`、`energy` は `low / mid / high`
- 既存の曲の書き方（コメント、キーの順序、`base:` による 2 番の共有）はできるだけ保つ

## melody 記法

`melody: "音名:拍数 ..."` の形で書く。

| 書き方 | 意味 |
|---|---|
| `C4:1` | 真ん中のドを 1 拍。`F#4:0.5` `Bb3:1/2` のように半音・小数・分数も可 |
| `E4` | 拍数を省略すると**直前と同じ長さ** |
| `r:1` | 1 拍の休符（`r` だけも可） |
| `G4:1~` | `~` を付けた音はメリスマ（新しい文字を歌わず、前の文字を伸ばしたまま音程だけ変える） |
| `\|` | 小節線（省略可。書くと位置が小節の区切りと合っているか検査される） |

- chords: `C | F C | G`（`|` で小節区切り、小節内はスペースで均等割り、`%` は前のコードの継続）
- melody の合計拍数は chords の合計拍数に合わせる（メロディが長いと警告、短いと残りは休符になる）
- 小節をまたぐ音は OK。`melody` を直したら小節線の位置も確認する

## 歌詞の規則

- **歌う音符の数 = 歌詞のモーラ数**（休符と `~` 付きの音は数えない）。合わないときは `fit: true` を付けるか、音符を割る・つなぐ
- 漢字は `{漢字|よみ}`。1 行 = 1 フレーズ。`/` か改行がフレーズの区切り
- 歌詞だけ替える（替え歌・2 番）ときは `python -m musicai kaeuta` を使うと、メロディが自動で合う

## 理論の判断基準（docs/01_音楽の作り方.md）

- 強拍（1・3 拍目）にはコードの構成音、弱拍は音階の隣の音。跳躍の後は逆方向へ戻る
- フレーズは山なり。終わりは長い音 + 休符（息継ぎ）。サビの最高音が曲の最高音
- 最後のフレーズは主音で終止すると「終わった感」が出る
- 盛り上がりは楽器数・音数・音域で作る（`energy` と `style`）

## 書き出す前に必ず実行する

1. 修正した YAML を保存する
2. `python -m musicai validate songs/{{曲名}}.yaml` → 合格にする
3. `python -m musicai check songs/{{曲名}}.yaml` → **警告ゼロ・音符数＝モーラ数**にする
4. 通ってから `python -m musicai render songs/{{曲名}}.yaml` で書き出す
5. 大きく直す前には、アプリの「バージョンを保存」で今の状態を残しておくよう、ユーザーに勧める
6. **曲を直接書き換えず、提案として出す**（ユーザーが「直接直して」と言ったときを除く）:
   `python -m musicai propose {{曲名}} --yaml <修正案のファイル> --title "何を直したか" --reason "理論的な理由"`。
   ユーザーがアプリの「💡 提案」で内容を確かめ、採用したときだけ曲に反映される（バージョンとしても記録される）

## 出力形式

次の 2 つに**分けて**出力する。

1. **修正後の YAML のみ**（曲全体をコードブロック 1 つで。`schema_version: 1` を含める。説明文は入れない）
2. **説明**（YAML の外）: 何をなぜ変えたか。**理論的な理由**（上の判断基準のどれに当たるか）を、変更箇所ごとに短く書く。`validate` と `check` の結果も添える
