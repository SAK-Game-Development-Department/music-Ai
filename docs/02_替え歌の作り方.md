# 替え歌の作り方

替え歌 = **メロディとコードはそのまま、歌詞だけ差し替える**。

## 手順

### 1. 元の曲を「曲ファイル（YAML）」にする

メロディ・コード・歌詞を書き起こします（例: `songs/hoshi.yaml`）。

```yaml
A:
  chords: "C | F C | F C | G C"
  melody: "C4:1 C4 G4 G4 | A4 A4 G4:2 | F4:1 F4 E4 E4 | D4 D4 C4:2"
  lyrics: "よぞらにひかる / ちいさなほしよ"
```

- 書き起こしが難しければ、**Claude に「この曲のメロディを書き起こして」**と頼むか、
  MIDI ファイルがあればそこから変換するのが早い（耳コピは AI と相談しながら）
- 著作権: 既存曲の替え歌を**公開**する場合は、元曲の権利者の許諾が必要になることがあります。
  個人で楽しむ範囲、またはパブリックドメインの曲（童謡・民謡・クラシックなど）を使うのが安全です

### 2. 新しい歌詞を書く

元の歌詞の**モーラ数とフレーズの区切り**を確認:

```bash
python -m musicai mora "よぞらにひかる / ちいさなほしよ"
# フレーズ1 (7モーラ): よ・ぞ・ら・に・ひ・か・る
# フレーズ2 (7モーラ): ち・い・さ・な・ほ・し・よ
```

新しい歌詞を、同じ区切り（`/` か改行）で書きます。漢字は `{漢字|よみ}`。

```yaml
# lyrics/ramen.yaml
A: "ラーメンたべたい / チャーシューおおめで"
B: "あついスープを / さいごまでのむ"
A2: "おなかいっぱい / ごちそうさま"
```

### 3. 自動調整して替え歌ファイルを作る

```bash
python -m musicai kaeuta songs/hoshi.yaml --lyrics-file lyrics/ramen.yaml --title ラーメンのうた -o songs/ramen.yaml
```

```
【A】
  元のメロディ: 歌う音 14 個 / 2 フレーズ
  新しい歌詞: 16 モーラ / 2 フレーズ
    △ フレーズ1: 7音 ← 8モーラ  音符を 1 回分割
    △ フレーズ2: 7音 ← 8モーラ  音符を 1 回分割
```

1 セクションだけなら:

```bash
python -m musicai kaeuta songs/hoshi.yaml --section A --lyrics "あたらしい / かし"
```

### 4. 聴いて直す

```bash
python -m musicai render songs/ramen.yaml
```

`output/ramen.mp3` を聴き、気になる所は `songs/ramen.yaml` の `melody` を手で（または Claude に頼んで）直します。

## 自動調整のルール

| 状況 | やること | 例 |
|---|---|---|
| 歌詞が多い | いちばん長い音符を半分に割る（同じ高さの連打）。フレーズ末の伸ばしはなるべく残す | `G4:2` → `G4:1 G4:1` |
| 歌詞が少ない ① | 同じ高さで隣り合う音をつなげる | `D4:1 D4:1` → `D4:2` |
| 歌詞が少ない ② | それでも余る音は**メリスマ**（前の文字を伸ばしたまま音程だけ変える） | `E4:1~`（`~` 付きの音は新しい文字を歌わない） |
| フレーズ数が一致 | フレーズごとに合わせる（息継ぎの位置が保たれる） | |
| フレーズ数が違う | 全体のモーラを元の音数の比率で配分 | |

休符がなくても、長い音（1.5 拍以上）の後ろをフレーズの切れ目として扱います。

## メロディ・歌詞の細かい書き方

| 書き方 | 意味 |
|---|---|
| `C4:1` | ド（真ん中）を 1 拍 |
| `F#4:0.5` / `Bb3:1/2` | 半拍（8 分音符） |
| `r:1` | 1 拍休み |
| `E4` | 拍数を省略すると直前と同じ長さ |
| `G4:1~` | メリスマ（前の文字のまま） |
| `|` | 小節線（省略可、書くと長さチェックされる） |
| 歌詞 `~` | その音符では前の文字を伸ばす |
| 歌詞 `/` か改行 | フレーズの区切り |
| 歌詞 `{空|そら}` | 漢字と読み |

## 上手な替え歌のコツ（自動ではできない部分）

1. **アクセントを合わせる**: メロディが上がる所で言葉も上がると聞き取りやすい
   （「あ↗め（飴）」と「あ↘め（雨）」）
2. **伸ばす音には開いた母音（あ・お）**、高音で「い・う」は避ける
3. **元歌詞の韻・言葉遊びの位置を真似る**と「替え歌感」が出る
4. **小さい「っ」は短い音符**に乗せると自然。長い音符に乗ると不自然
5. 迷ったら Claude に「この行のアクセントとメロディが合っているか見て」と聞く

## YouTube・音声ファイルの曲で替え歌を作る

アプリの「🎤 替え歌」→「YouTube・音声ファイルから」で、
**YouTube の URL を貼る**か **音声ファイル（mp3 / m4a / wav）を選ぶ**だけで、元の曲を取り込めます。

```bash
# コマンドの場合
python -m musicai import "https://www.youtube.com/watch?v=..." --start 45 --end 90
python -m musicai import 曲.mp3 --start 45 --end 90 --title サビ
```

### 自動でやること

| 何を | どうやって |
|---|---|
| テンポ | 音の立ち上がり（ドラムなど）の周期 |
| キー | 12 音の強さの分布と、出てくるコードがその調に収まるか |
| コード | 小節ごとに 12 音の強さをコードの形と照合 |
| 歌メロ | ステレオの真ん中（ボーカルの位置）を強調し、倍音の重なりから一番目立つ音の高さを追う → 16 分音符単位の音符に |
| カラオケ音源 | 真ん中のボーカル帯域を弱めた伴奏を作り、替え歌の伴奏に使う |

取り込んだ曲は 8 小節ごとの「パート1, パート2…」に分かれ、各フレーズの**音の数**が表示されます。
その数に合わせて新しい歌詞を書けば、あとは普通の替え歌と同じです（数がずれても自動で合わせます）。

### 精度について（大事）

- 自動の聴き取りなので **完璧ではありません**。テストでは、音の高さが合っている音符は
  シンプルな曲で約 7 割、伴奏が厚いサビで約 5 割でした（テンポ・キー・コードはほぼ正確）
- 「🎹 編集・再生」の **「🎧 元の音源と聴き比べ」** で、元の歌とピアノロールを合わせて確認できます。
  ずれている所は曲データを直接直すか、Claude に「パート1 のフレーズ2 を元の曲に合わせて直して」と頼んでください
- **範囲はサビなど 30 秒〜1 分**にすると、速く・正確になります
- ソースから使う場合、`pip install demucs` しておくと AI のボーカル分離を使って **精度が大きく上がります**
  （カラオケ音源もきれいになります。初回はモデルのダウンロードがあります。exe 版には含まれません）

### 伴奏の切り替え

「編集・再生」の「伴奏」で選べます。

| 伴奏 | 内容 |
|---|---|
| 元の音源（カラオケ化） | 取り込んだ曲のボーカルを弱めた伴奏 + 新しい歌詞のメロディ（既定） |
| 自動アレンジ | 聴き取ったコードから、このアプリが伴奏を作り直す |
| 両方 | 重ねる |

### 権利について

取り込んだ曲や替え歌は **個人で楽しむ範囲** で使ってください。
公開（動画投稿など）する場合は元の曲の権利者の許諾が必要になることがあります。YouTube の利用規約にも従ってください。
