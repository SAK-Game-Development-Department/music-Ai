# 替え歌の作り方

替え歌 = **メロディとコードはそのまま、歌詞だけ差し替える**。

## 手順

### 1. 元の曲を「曲ファイル（YAML）」にする

メロディ・コード・歌詞を書き起こします（例: `songs/hoshi.yaml`）。

```yaml
A:
  chords: "C | F C | F C | G C"
  melody: "C4:1 C4 G4 G4 | A4 A4 G4:2 | F4:1 F4 E4 E4 | D4 D4 C4:2"
  lyrics: "よぞらにひかる / ちいさなほしよ"
```

- 書き起こしが難しければ、**Claude に「この曲のメロディを書き起こして」**と頼むか、
  MIDI ファイルがあればそこから変換するのが早い（耳コピは AI と相談しながら）
- 著作権: 既存曲の替え歌を**公開**する場合は、元曲の権利者の許諾が必要になることがあります。
  個人で楽しむ範囲、またはパブリックドメインの曲（童謡・民謡・クラシックなど）を使うのが安全です

### 2. 新しい歌詞を書く

元の歌詞の**モーラ数とフレーズの区切り**を確認:

```bash
python -m musicai mora "よぞらにひかる / ちいさなほしよ"
# フレーズ1 (7モーラ): よ・ぞ・ら・に・ひ・か・る
# フレーズ2 (7モーラ): ち・い・さ・な・ほ・し・よ
```

新しい歌詞を、同じ区切り（`/` か改行）で書きます。漢字は `{漢字|よみ}`。

```yaml
# lyrics/ramen.yaml
A: "ラーメンたべたい / チャーシューおおめで"
B: "あついスープを / さいごまでのむ"
A2: "おなかいっぱい / ごちそうさま"
```

### 3. 自動調整して替え歌ファイルを作る

```bash
python -m musicai kaeuta songs/hoshi.yaml --lyrics-file lyrics/ramen.yaml --title ラーメンのうた -o songs/ramen.yaml
```

```
【A】
  元のメロディ: 歌う音 14 個 / 2 フレーズ
  新しい歌詞: 16 モーラ / 2 フレーズ
    △ フレーズ1: 7音 ← 8モーラ  音符を 1 回分割
    △ フレーズ2: 7音 ← 8モーラ  音符を 1 回分割
```

1 セクションだけなら:

```bash
python -m musicai kaeuta songs/hoshi.yaml --section A --lyrics "あたらしい / かし"
```

### 4. 聴いて直す

```bash
python -m musicai render songs/ramen.yaml
```

`output/ramen.mp3` を聴き、気になる所は `songs/ramen.yaml` の `melody` を手で（または Claude に頼んで）直します。

## 自動調整のルール

| 状況 | やること | 例 |
|---|---|---|
| 歌詞が多い | いちばん長い音符を半分に割る（同じ高さの連打）。フレーズ末の伸ばしはなるべく残す | `G4:2` → `G4:1 G4:1` |
| 歌詞が少ない ① | 同じ高さで隣り合う音をつなげる | `D4:1 D4:1` → `D4:2` |
| 歌詞が少ない ② | それでも余る音は**メリスマ**（前の文字を伸ばしたまま音程だけ変える） | `E4:1~`（`~` 付きの音は新しい文字を歌わない） |
| フレーズ数が一致 | フレーズごとに合わせる（息継ぎの位置が保たれる） | |
| フレーズ数が違う | 全体のモーラを元の音数の比率で配分 | |

休符がなくても、長い音（1.5 拍以上）の後ろをフレーズの切れ目として扱います。

## メロディ・歌詞の細かい書き方

| 書き方 | 意味 |
|---|---|
| `C4:1` | ド（真ん中）を 1 拍 |
| `F#4:0.5` / `Bb3:1/2` | 半拍（8 分音符） |
| `r:1` | 1 拍休み |
| `E4` | 拍数を省略すると直前と同じ長さ |
| `G4:1~` | メリスマ（前の文字のまま） |
| `|` | 小節線（省略可、書くと長さチェックされる） |
| 歌詞 `~` | その音符では前の文字を伸ばす |
| 歌詞 `/` か改行 | フレーズの区切り |
| 歌詞 `{空|そら}` | 漢字と読み |

## 上手な替え歌のコツ（自動ではできない部分）

1. **アクセントを合わせる**: メロディが上がる所で言葉も上がると聞き取りやすい
   （「あ↗め（飴）」と「あ↘め（雨）」）
2. **伸ばす音には開いた母音（あ・お）**、高音で「い・う」は避ける
3. **元歌詞の韻・言葉遊びの位置を真似る**と「替え歌感」が出る
4. **小さい「っ」は短い音符**に乗せると自然。長い音符に乗ると不自然
5. 迷ったら Claude に「この行のアクセントとメロディが合っているか見て」と聞く

## YouTube・音声ファイルの曲で替え歌を作る

アプリの「🎤 替え歌」→「YouTube・音声ファイルから」で、
**YouTube の URL を貼る**か **音声ファイル（mp3 / m4a / wav）を選ぶ**だけで、元の曲を取り込めます。

```bash
# コマンドの場合
python -m musicai import "https://www.youtube.com/watch?v=..." --start 45 --end 90
python -m musicai import 曲.mp3 --start 45 --end 90 --title サビ
```

### 自動でやること

| 何を | どうやって |
|---|---|
| テンポ | 音の立ち上がり（ドラムなど）の周期 |
| キー | 12 音の強さの分布と、出てくるコードがその調に収まるか |
| コード | 小節ごとに 12 音の強さをコードの形と照合 |
| 歌メロ | ステレオの真ん中（ボーカルの位置）を強調し、倍音の重なりから一番目立つ音の高さを追う → 16 分音符単位の音符に |
| カラオケ音源 | 真ん中のボーカル帯域を弱めた伴奏を作り、替え歌の伴奏に使う |

取り込んだ曲は 8 小節ごとの「パート1, パート2…」に分かれ、各フレーズの**音の数**が表示されます。
その数に合わせて新しい歌詞を書けば、あとは普通の替え歌と同じです（数がずれても自動で合わせます）。

### 精度について（大事）

- 自動の聴き取りなので **完璧ではありません**。テストでは、音の高さが合っている音符は
  シンプルな曲で約 7 割、伴奏が厚いサビで約 5 割でした（テンポ・キー・コードはほぼ正確）
- 「🎹 編集・再生」の **「🎧 元の音源と聴き比べ」** で、元の歌とピアノロールを合わせて確認できます。
  ずれている所は曲データを直接直すか、Claude に「パート1 のフレーズ2 を元の曲に合わせて直して」と頼んでください
- **範囲はサビなど 30 秒〜1 分**にすると、速く・正確になります
- ソースから使う場合、`pip install demucs` しておくと AI のボーカル分離を使って **精度が大きく上がります**
  （カラオケ音源もきれいになります。初回はモデルのダウンロードがあります。exe 版には含まれません）

### 伴奏の切り替え

「編集・再生」の「伴奏」で選べます。

| 伴奏 | 内容 |
|---|---|
| 元の音源（カラオケ化） | 取り込んだ曲のボーカルを弱めた伴奏 + 新しい歌詞のメロディ（既定） |
| 自動アレンジ | 聴き取ったコードから、このアプリが伴奏を作り直す |
| 両方 | 重ねる |

### 権利について

取り込んだ曲や替え歌は **個人で楽しむ範囲** で使ってください。
公開（動画投稿など）する場合は元の曲の権利者の許諾が必要になることがあります。YouTube の利用規約にも従ってください。

## 歌詞を自動で作る

替え歌画面の ② で **「🪄 歌詞を自動で作る」** にチェックを入れると、各フレーズの音の数に **ぴったり合う歌詞** が入ります。
歌詞を 1 文字も書かなくても替え歌が作れます。

| 設定 | 内容 |
|---|---|
| 📖 ストーリー性をつける（自動生成がオンのときだけ表示） | オン: テーマを 1 つに決め、曲の頭から終わりへ「はじまり → 日々 → 変化 → 想い」（起承転結）と話が進む。オフ: 1 行ずつ場面がばらばらの、言葉遊びのような歌詞 |
| テーマ | おまかせ / 恋 / 友情 / 夢 / 夏 / 冬 / ごはん |
| 🎲 別の歌詞 | 別の案に作り直す |

- 入った歌詞（点線の枠）は自由に書き換えられます。**書き換えたパートは「別の歌詞」でも消えません**
- 一部のパートだけ自分で書き、残りを自動にすることもできます（空のパートは「替え歌を作る」を押したときに自動で埋まります）
- 1 行は必ず「（つなぎの言葉）＋ 文として終われる言葉」の形で作るので、「〜を」「〜けど」で行が終わることはありません
- **元の歌詞がある曲**では「原曲と同じ感じ」に寄せます: 同じ行の長さ、原曲で同じ歌詞をくり返す所（サビなど）は新しい歌詞も同じ行をくり返す、各行の最後の母音（韻）を原曲にそろえる
- 元の歌詞がないときは、偶数行の最後の母音を前の行にそろえる（韻を踏む）ようにしています
- 聴き取りで細切れになった短いフレーズ（3 音以下）は、となりのフレーズとまとめて 1 行にします

## 間奏（歌わないパート）

YouTube・音声ファイルから取り込むと、**歌っていない小節**（イントロ・間奏・アウトロ）を自動で見分けて、
「イントロ」「間奏1」「アウトロ」などの **歌わないパート** に分けます（ボーカルはふつう音の真ん中から聞こえることと、聴き取れた音の数から判断）。

- 替え歌画面の各パートの **「🎵 このパートを歌う」** で切り替えられます。外したパートは歌詞を付けず、再生でも歌いません
- 判定がずれていたら、チェックを付け外しするだけで直せます（歌うにすると、自動生成オンならその場で歌詞が入ります）
- 曲データでは、歌わないパートに `sing: false` が付きます
- インターネットや AI サービスを使わない、アプリ内蔵の作り方なので、exe 版でもオフラインで動きます。
  そのぶん言い回しは定番のフレーズの組み合わせです。もっと凝った歌詞にしたいときは、できた歌詞をたたき台にして Claude に直してもらうのがおすすめです

```bash
# コマンドの場合
python -m musicai kaeuta songs/hoshi.yaml --auto-lyrics --theme 夏 -o songs/natsu.yaml
python -m musicai kaeuta songs/hoshi.yaml --auto-lyrics --no-story --seed 3 -o songs/asobi.yaml
```

## 原曲の歌詞を使う（おすすめ）

原曲の歌詞があると、**歌っている所と間奏の区別**と、**替え歌の歌詞づくり**が正確になります。

### 原曲の歌詞の入れ方

| 方法 | どうなるか |
|---|---|
| YouTube の動画に**歌詞の字幕**がある | 取り込むときに自動で読み込みます。**字幕の出ている所 = 歌、出ていない所 = 間奏**として、行をその時間のパートに入れます |
| 取り込むときに「📝 原曲の歌詞（任意）」に貼る | 歌のパートに、順番どおり・長さが合うように行を入れます。1 行も入らなかったパートは間奏になります |
| 取り込んだあとで、替え歌画面 ② の「📝 原曲の歌詞を貼り付ける」 | 同上（すでに取り込んだ曲にもあとから入れられます） |

- 漢字のまま貼って大丈夫です（読みは自動で調べます。曲データでは `{漢字|よみ}` になるので、読みが違っていたら直せます）
- 1 行 = 1 フレーズ、ブロック（A メロ・サビなど）の間は空行にすると、パートへの割り当てが正確になります
- 原曲の歌詞を入れたパートのメロディは、歌詞の長さに合わせて自動で調整されます（`fit: true`）

### 「原曲をきれいに替える」歌詞づくり

原曲の歌詞があるパートでは、自動の歌詞を **原曲の骨組みを残して言葉だけ入れ替える** 形で作ります。

- **残すもの**: 助詞（が・を・まで など）、語尾（〜よ・〜ね）、「まだ」「きっと」などの言い回し、くり返し出てくる決めの言葉
- **入れ替えるもの**: 名詞・動詞・形容詞を、テーマの言葉で **同じ長さ（モーラ数）** のものに
- 行の長さは原曲と同じ。原曲でくり返す行（サビなど）は、新しい歌詞も同じ行をくり返す
- ちょうど同じ長さの言葉がない所は、原曲の言葉のまま残します（無理に変えない）

例（テーマ「夏」）:

| 原曲 | 替え歌 |
|---|---|
| 窓を開けたら | うみを あけたら |
| 風が運んだ | くもが はこんだ |
| 不安もあるけど | ラムネも あるけど |
| 空まで届け | かぜまで とどけ |

原曲の歌詞がひらがなだけの曲や、骨組みをうまく読み取れない行は、これまでどおりテーマのフレーズを組み合わせて作ります。

## Whisper で歌詞と歌い出しのタイミングを聴き取る

取り込むときに **「🎙 Whisper で歌詞と歌い出しのタイミングを聴き取る」** にチェックを入れると（おすすめ・初期値オン）、
OpenAI の音声認識モデル **Whisper** で歌声を聴き取り、**どこで・どのタイミングで歌い始めているか** を調べて歌詞を合わせます。

1. 歌を強調した音（ステレオの真ん中を残し、低音を弱めたもの）を Whisper に聞かせ、言葉ごとの時刻を得る
2. 原曲の歌詞がある（貼り付け・字幕）ときは、Whisper の聴き取りと突き合わせて、歌詞の **1 モーラずつの歌い出しの時刻** を決める
   （聴き間違いの所は前後から補間。原曲の歌詞は Whisper にもヒントとして渡すので、聴き間違いが減る）。
   原曲の歌詞がないときは、Whisper の聴き取りをそのまま原曲の歌詞にする
3. 歌メロの聴き取りで見つけた「音の頭」に、モーラの時刻を細かく寄せる
4. **その時刻に音符を置いて** メロディを作り直す（音の高さは、その時刻の歌声の高さ）。歌詞 1 モーラ = 音符 1 つになる
5. 歌詞の出ている小節 = 歌、それ以外 = 間奏

取り込み済みの曲は、替え歌画面 ② の「📝 原曲の歌詞を貼り付ける」の中の **「🎙 Whisper でタイミングを合わせ直す」** で、
元の音源から合わせ直せます（結果は「（Whisper）」の付いた新しい曲として保存。元の曲は変わりません）。

| モデル | 目安 |
|---|---|
| tiny / base | 速いが聴き取りは粗い |
| **small（おすすめ）** | 速さと正確さのバランス。原曲の歌詞を貼るならこれで十分なことが多い |
| medium / large-v3 | 正確だが遅い（CPU だと曲の長さの数倍かかることも） |

- アプリ版（exe など）には Whisper（faster-whisper: OpenAI の Whisper モデルを軽く動かす実装）が入っています。
  ソースから使う場合は、初めて使うときに自動でインストールします（`openai-whisper` が入っていればそちらを使います）
- モデルは初回だけダウンロードされます（small で約 500MB）。2 回目からはすぐ使えます
- 歌は音楽と重なっているので、話し声ほど正確には聴き取れません。**原曲の歌詞を貼り付けると、タイミング合わせがずっと正確になります**
