music-Ai（Mac 版）
=================

【起動】 music-Ai をダブルクリック
  → ターミナルが開き、少しするとブラウザにアプリ画面が出ます（初回は 10 秒ほどかかります）
  → 終了するときはターミナルのウィンドウを閉じてください

【初回に「開発元を検証できないため開けません」と出たら】
  1. music-Ai を右クリック（control + クリック）→「開く」→「開く」
  2. それでも開けない場合: システム設定 →「プライバシーとセキュリティ」→ 下の方の「このまま開く」
  （署名していないアプリのため表示されます）

【保存場所】 music-Ai と同じフォルダの songs（曲）と output（音源・MIDI・楽譜）
  ※ 書き込めない場所から起動した場合は「ホーム/music-Ai」に保存されます

【Intel Mac と Apple シリコン（M1〜）】
  music-Ai-mac-apple-silicon.zip … M1/M2/M3/M4 などの Mac
  music-Ai-mac-intel.zip        … Intel の Mac

【MP3 で保存したいとき】 Homebrew で `brew install ffmpeg`（なくても WAV で再生・保存できます）
